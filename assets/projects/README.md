# Project media

Drop your images and videos here — one folder per project.
The page shows a dashed placeholder until the file exists; as soon as you add
a file with the right name, the placeholder disappears and your media shows.

| Slot        | File to add                    |
|-------------|--------------------------------|
| Cover image | `<project>/01.jpg`             |
| Image 02    | `<project>/02.jpg`             |
| Image 03    | `<project>/03.jpg`             |
| Video       | `<project>/video.mp4`          |
| Image 04    | `<project>/04.jpg`             |

Projects: `hey-gigi`, `partnership-event`, `influencer-marketing`, `ooh-italy`, `paid-media`, `social-media`

Tips: JPG for photos (max ~1600px wide keeps it fast), MP4 (H.264) for video.
Want more slots on a page? Just ask.

## How the placeholders behave

- **Working locally** (opening the file or localhost): you see the dashed slots
  with the exact filename to drop in — your checklist of what's still missing.
- **On the live site**: empty slots are hidden automatically, so visitors never
  see unfinished boxes. A gallery with nothing in it disappears entirely.

So you can publish at any time and only the media you've actually added shows up.
